# project-name511151
В косметической промышленности поиск оптимального сочетания ингредиентов и параметров обработки имеет решающее значение для обеспечения качества продукта и срока его хранения. Этот синтетический набор данных имитирует эксперимент на уровне лаборатории или опытно-промышленного производства, в ходе которого различные косметические составы готовились при разных температурных условиях. Цель этого набора данных — изучить, как исходные параметры процесса (тип формулы и температура смешивания) влияют на ключевые физические характеристики и показатели качества (вязкость, pH и стабильность).
